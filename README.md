# LEG_MRI
To develop an automated thigh Dixon MRI phenotyping pipeline for early dysglycemia screening and evaluate its clinical interpretability via static metabolic profiling and dynamic physiological mapping.
An automated 3D convolutional neural network based on the nnU-Net framework was implemented to delineate skeletal muscle, IMAT, subcutaneous fat, and bone from the thigh Dixon MRI. Inputs included water, fat, and fatfraction (FF) images(27)
